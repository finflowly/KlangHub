# Licence texts

Full texts of the copyleft licences that cover components KlangHub ships. They are here, rather than
only linked, because LGPL-2.1 §1, LGPL-3.0 §4 and MPL-1.1 §3.5 each ask that a copy of the licence
accompany the distribution — a URL is a reference, not a copy.

| File | Applies to |
|---|---|
| `LGPL-2.1.txt` | LAME (`libmp3lame.*.dll`, shipped by NAudio.Lame) · Ude.NetStandard, if the LGPL option is taken |
| `LGPL-3.0.txt` | CUETools.Codecs.FLAKE / CUETools.Codecs (the FLAC encoder) |
| `MPL-1.1.txt`  | Ude.NetStandard, if the MPL option is taken |
| `GPL-3.0.txt`  | referenced by LGPL-3.0, which is written as a set of additional permissions on top of it |

Which component is under what, and how each obligation is met, is set out in
[../docs/THIRD-PARTY-LICENSES.md](../docs/THIRD-PARTY-LICENSES.md).
